# 我们这一页 · 独立交互预览

以照片、文字与纪念感为核心的双人生活手账。此版本供用户验证产品和交互，尚未接入家庭网站。

## 启动

在本工作副本的仓库根目录运行：

```powershell
npm ci --no-audit --no-fund
node node_modules/vite/bin/vite.js --config preview/our-page/vite.config.js
```

- 完整预览：http://127.0.0.1:5176/
- 手机尺寸预览：http://127.0.0.1:5176/mobile.html
- 仅监听本机，不发布外网。
- 关闭开发服务后，可用上述命令重新启动。

构建验证：

```powershell
node node_modules/vite/bin/vite.js build --config preview/our-page/vite.config.js
```

## 已实现

- 照片或文字记录、日期与参与人、草稿、新增、作者编辑和删除确认。
- JPG / PNG / WebP 本地选图与压缩；正文按普通文本渲染。
- 双人署名回应、可撤回的「我记得」、个人与双方珍藏筛选。
- 按自然周整理最多三段回忆，双方分别写话，草稿保留，明确共享。
- 每周回忆页的打印 / PDF 样式。
- 心里话草稿与共享、双方回应、约定提议和分别接受。
- 约定修订保留历史并重新征求双方接受；双方分别反馈，一方不能替另一方标记释怀。
- 当前浏览器本地保存、同源预览窗口更新、导出备份、恢复示例确认。
- 原生对话框、键盘焦点和 Escape、未保存文字提示、移动布局与减少动态效果支持。

## 验收建议

1. 以 Aosen 记录一件小事，保存后刷新。
2. 切换到小悦，补一句回应，点「我记得」并珍藏。
3. 打开「这一周」，挑选回忆，给这一周写一句话。
4. 写一段心里话，先存草稿，再明确共享。
5. 双方分别接受约定；其中一方选择「还需要调整」，确认不会自动标记为双方都已释怀。
6. 修改约定，确认保留历史并需要双方重新接受。
7. 打开手机尺寸预览，体验输入表单和底部导航。

## 隔离边界

所有新增文件均在 `preview/our-page/`。现有 `src/`、API、路由、数据库、部署配置与主分支均未改动。

预览使用专用本地存储键 `family-our-page-preview-v1`，不读取正式家庭数据，不连接 Supabase，不发送通知。照片仅留在当前浏览器。

身份选择只用于演示，不能用于安全认证。草稿在产品列表中不对另一身份展示，但该预览不提供个人隐私隔离，也不支持不同设备同步。正式接入需另外实现身份权限、可靠存储、并发更新和媒体管理。这里没有积分、扣分、排行榜、自动情绪判断或 AI 代写感受。

浏览器实际验证了记录草稿与恢复、记录保存并刷新、本地 JPG 选图与照片记录刷新后打开、切换身份、回应、认可、珍藏、每周文字草稿跨页面保留、每周回忆挑选、心里话草稿与主动共享、约定分别接受、单方反馈不自动结案、约定修订与历史保留。检查了 375px 手机竖屏与 667px 横屏布局，桌面内容宽度与视口一致，示例图片均正常加载。浏览器运行日志未发现警告或错误。

原生打印 / PDF 最终输出、真实设备系统相册选择尚未做端到端验收；可在用户验证时继续检查。
