# 我们这一页 · 独立交互预览

以照片、文字与纪念感为核心的双人生活记录。此版本供用户验证产品和交互，尚未接入家庭网站。

## 启动

在本工作副本的仓库根目录运行：

```powershell
npm ci --no-audit --no-fund
node node_modules/vite/bin/vite.js --config preview/our-page/vite.config.js
```

- 完整预览：http://127.0.0.1:5176/
- 生活页入口预览：http://127.0.0.1:5176/?entry=life
- 手机尺寸预览：http://127.0.0.1:5176/mobile.html
- 仅监听本机，不发布外网。
- 关闭开发服务后，可用上述命令重新启动。

构建验证：

```powershell
node node_modules/vite/bin/vite.js build --config preview/our-page/vite.config.js
```

## 已实现

- 放置在「生活 → 我们这一页」，提供生活页入口卡片示意，可直接记录或进入日常。
- 沿用家庭网站的背景照片、系统字体、半透明卡片、胶囊导航与蓝色按钮。
- 表单顶部明确选择记录人 Aosen / 小悦，保存和存草稿后记住选择；记录、回应、心里话都有署名，编辑时保留原记录人。
- 记录只需填一句正文，标题自动补全，日期默认今天，照片可选；保留草稿、编辑与删除确认。
- 草稿随选择的记录人保存；切换作者不会静默覆盖另一人的已有草稿，发布或编辑也不会误删无关草稿。
- JPG / PNG / WebP 本地选图与压缩；正文按普通文本渲染。
- 主导航精简为「日常 / 心里话」，日常不再设置人群与参与人筛选；保留署名回应、可撤回的「我记得」和珍藏。
- 每周回顾与珍藏为次要入口；按自然周自动取最近三段回忆，双方可分别写一句话，不再手动挑选。
- 每周回忆页的打印 / PDF 样式。
- 心里话草稿与共享、双方回应；小约定默认折叠，需要时再展开。
- 约定修订保留历史并重新征求双方接受；双方分别反馈，一方不能替另一方标记释怀。
- 当前浏览器本地保存、同源预览窗口更新、导出备份、恢复示例确认。
- 原生对话框、键盘焦点和 Escape、未保存文字提示、移动布局与减少动态效果支持。

## 验收建议

1. 点「留住这一刻」，在表单顶部选小悦，只写正文并保存；刷新后确认署名和默认记录人。
2. 切换到 Aosen，给小悦的记录回应；确认原作者仍为小悦、回应作者为 Aosen。
3. 从「每周回顾」查看自动整理的回忆，再试试「珍藏」。
4. 写一段心里话，先存草稿，再明确共享。
5. 展开可选的小约定，双方分别接受约定；其中一方选择「还需要调整」，确认不会自动标记为双方都已释怀。
6. 修改约定，确认保留历史并需要双方重新接受。
7. 点家庭导航「生活」查看入口位置，分别试试「记一件小事」与「看看我们的日常」。
8. 打开手机尺寸预览，体验记录人选择、单列卡片与表单。

## 隔离边界

所有新增文件均在 `preview/our-page/`。现有 `src/`、API、路由、数据库、部署配置与主分支均未改动。

预览使用专用本地存储键 `family-our-page-preview-v1`，不读取正式家庭数据，不连接 Supabase，不发送通知。照片仅留在当前浏览器。

身份选择只用于演示，不能用于安全认证。草稿在产品列表中不对另一身份展示，但该预览不提供个人隐私隔离，也不支持不同设备同步。正式接入需另外实现身份权限、可靠存储、并发更新和媒体管理。这里没有积分、扣分、排行榜、自动情绪判断或 AI 代写感受。
